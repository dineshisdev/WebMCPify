# WebMCPify

Make today's web callable by tomorrow's agents.

Paste a URL → discover capabilities → generate WebMCP tools → agent-ready site.

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router) on Vercel
- Cloudflare Workers (HTMLRewriter overlay) — not in this commit yet
